# Taskify - Mobile App Capstone Project

**Taskify** is a React Native mobile application developed for the IBM Mobile App Development Capstone Project. The app includes user authentication, live REST API data fetching, local state persistence, stack navigation, and custom notification alerts.

---

## 📱 Features

- **Authentication System:** Signup and Login screens with state-driven input handling.
- **Task Dashboard:** Dynamic list rendering task items fetched asynchronously from a REST API.
- **Detailed Item View:** Contextual view displaying item details and alert setup triggers.
- **Settings & Theme Persistence:** Dark mode toggle with preferences saved to `AsyncStorage`.
- **Navigation Bar:** Modular header component facilitating smooth screen transitions.
- **Notification Alerts:** Interactive alerts for task management reminders.

---

## 🛠️ Tech Stack

- **Framework:** React Native
- **Language:** JavaScript (ES6+)
- **Storage:** `@react-native-async-storage/async-storage`
- **Data Source:** JSONPlaceholder REST API (`https://jsonplaceholder.typicode.com/todos`)
