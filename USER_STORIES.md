# App User Stories

1. As a new user, I want to create an account using my username, email, and password so I can access the app.
2. As a registered user, I want to log in securely with my email and password so I can view my personalized dashboard.
3. As a user, I want to view a Home Screen with a custom app header and logo to easily navigate features.
4. As a user, I want to tap on a task/item to navigate to a Detail Screen and view its complete information.
5. As a user, I want to save items to my Favorites/Profile page so I can quickly access them later.
6. As a user, I want my app preferences and session data saved locally so my settings persist after restart.
7. As a user, I want the app to fetch and display real-time data from an external API so I receive updated content.
8. As a user, I want to open a Settings Menu with clear items so I can configure my dark mode and profile settings.
9. As a user, I want to configure and receive notification alerts so I never miss important task reminders.
